# ⚡ THE SYSTEM: Real-Life Mastery HUD & Performance OS

A native Android application themed directly after the iconic **Solo Leveling System HUD interface**, but engineered strictly for **realistic, real-world human performance and bio-hacking**.

The app strips away fantasy dungeons and monsters, replacing them with **real-life high-performance operations, science-backed discipline protocols, hydration tracking, live deep-work focus sprints, calisthenics, and step metrics**—all orchestrated by **Gemini Intelligence**.

Instead of arbitrary fantasy tasks, daily quests represent genuine high-performance lifestyle pillars:

- **Skill Mastery & Reading:** Daily knowledge acquisition tracking (`20 min` target) with quick-log (`+10 min`).

## 🛠️ Building & CI/CD

On every push to `main`, GitHub Actions automatically builds the debug APK and publishes a downloadable GitHub release.

### Local Build:
```bash
# Windows
.\gradlew.bat assembleDebug

# Linux / macOS
chmod +x gradlew
./gradlew assembleDebug
```
The output APK will be at: `app/build/outputs/apk/debug/app-debug.apk`.
